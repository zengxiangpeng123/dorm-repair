## 三、SYS-005 对标结论

- 服务端口：学生端 5173、师傅端 5174、管理端 5175、后端 8082、AI 8001；三端独立构建并固定端口。
- 返修流程：学生只提交申请；管理员审查通过后才执行 `REJECT`、原单转 `REWORKING`，并生成子单。
- 审查期间原单保持 `VERIFYING`，暂停自动验收；驳回后 T1 从审查决定时刻重新计时。
- 状态机保持 9 状态 / 14 转移，不新增状态位；审查链路由 `REWORK_REQUEST`、`REJECT`、`REWORK_REJECTED` 事件表达。
- 当前实现已对齐 SYS-005 已审查口径。

## 四、实现状态

- 三端独立前端、后端与 AI 服务、迁移期 20 张业务表 + 1 个兼容视图（运行库另有迁移记录表）、9 状态/14 转移、真实模型复核和完整测试均已实现。
- 返修流程为“学生提交申请 → 管理员审查 → 通过后生成 -R{n}”；误报驳回，原单继续验收/归档。
- Bearer Token（数据库摘要会话、重启恢复与撤销）、三角色分表、按楼栋派工、T1/T2、返修审查队列及三端独立应用均已运行验证。
