## 正式上线前必须补齐

1. 在目标主机部署 Compose 栈，使用真实证书、生产 S3 桶和真实 Alertmanager 接收器。
2. 执行 `deploy/scripts/preflight.sh`，再执行数据库备份、迁移、服务启动和 smoke。
3. 完成至少一轮真实用户业务链、告警通知、备份恢复与版本回滚演练。
4. 记录监控观察期、缺陷处置、值班责任人与业务验收签字。

只有以上证据齐全后，才能把“本地预验收”改为“正式生产准入”。
