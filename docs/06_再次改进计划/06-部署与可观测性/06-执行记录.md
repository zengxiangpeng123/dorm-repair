## 实际改动

- Spring Boot 增加 Actuator liveness/readiness 和 Prometheus 指标端点。
- 增加请求 ID、状态码、耗时访问日志，日志不包含请求体、令牌或照片内容。
- Python AI 服务增加请求日志和 `/metrics`。
- 新增后端、AI、三端静态站点的 Dockerfile 与 Compose 编排。
- 新增 Nginx HTTPS、反向代理、安全响应头与三端路径配置。
- 新增 Prometheus 抓取配置和异常、延迟、服务不可用告警规则；告警接收器需在目标环境配置。
- 新增 MySQL 备份、恢复、校验脚本和备份保留说明。
- S3 支持 IAM Role 或静态 Access/Secret/Session 凭据；生产启动拒绝不完整组合。
- readiness 纳入数据库和文件存储检查，S3 使用 HeadBucket 验证桶可访问。
- 新增 `deploy/scripts/migrate.sh` 和 PowerShell 入口；旧库迁移使用 `t_schema_migration` 记录文件名和 SHA-256，重复执行自动跳过，内容变更拒绝继续。
- 修正容器健康检查，镜像内显式安装 curl，并检查 readiness 的实际状态。
- S3 客户端关闭不兼容的 aws-chunked 分块编码，兼容 OSS/部分 S3 兼容服务；readiness 仍执行 HeadBucket。
- 业务配置缓存增加过期刷新：多实例修改 `t_config` 后，其他实例最多 60 秒内读到新值。
- 定时器扫描改为只查询 `VERIFYING/DONE` 工单，避免每 30 秒加载全部历史工单、事件和照片。
- 管理端工单列表支持服务端分页：状态过滤与 LIMIT/OFFSET 在 MySQL 下推，只加载当前页事件和照片；pageSize 上限 200。真实 MySQL 验证 6 条数据分页、总数和 hasMore 正确。
- 我的工单同步改为身份范围分页：学生只查自己的 student_id，师傅只查派给自己的 worker_id，范围过滤与 LIMIT/OFFSET 在 MySQL 下推；真实 MySQL 验证学生 3 单、师傅 4 单均只返回本人数据。
- 师傅工作台改为专用范围查询：只取本人在办工单和近 24 小时已完成工单，历史归档不参与每次到楼刷新；真实 MySQL 验证仅返回 W0428 的 ASSIGNED/PARTS/REPAIRING 在办单。
- 备份/恢复脚本改用临时 MySQL 选项文件传递凭据，避免密码出现在进程列表；恢复必须显式设置 `RESTORE_CONFIRM=<库名>`，空或截断备份会失败并删除。
- 生产启动门禁新增 S3 endpoint HTTPS 校验；数据库 SSL 与公钥获取改为显式配置。
- 数据库 TLS 增加 `DB_SSL_VERIFY_SERVER_CERTIFICATE=true` 强制门禁：生产 profile 同时要求 `useSSL=true` 与 `verifyServerCertificate=true`，避免只加密但不校验证书身份。
- 新增 Alertmanager 接收器模板与 Compose 内部 Alertmanager 服务；生产必须配置真实通知渠道并做测试告警。
- 新增 `deploy/scripts/preflight.sh` / `.ps1`，启动前校验证书、必要环境变量、HTTPS S3、数据库 SSL、真实告警接收器和完整 schema 契约。
