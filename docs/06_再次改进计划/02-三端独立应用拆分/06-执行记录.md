## 实际改动

- 新建 `app/student-web`、`app/worker-web`、`app/admin-web`，分别固定 5173/5174/5175 并启用 `strictPort`。
- 三端使用独立 session key：`dorm.student.session`、`dorm.worker.session`、`dorm.admin.session`。
- 三端 Vite `base` 分别固定为 `/student/`、`/worker/`、`/admin/`，与 Nginx 子路径部署一致；构建产物检查同时校验入口资源前缀、文件存在性、会话键和跨端路由。
- 新建 `app/web/packages/contract`，仅共享状态、事件和展示纯函数。
- 学生建单不再调用 `/assign`；后端提交事务内按楼栋自动派工。
- 师傅端移除管理员命令与 `role: 'admin'`；待配件改为只读，配件到货移到管理端。
- 管理端移除 `/demo/reset`、`/demo/advance`、快进与重置入口。
- 三端进入受保护路由时调用 `/auth/me` 刷新身份，退出时撤销服务端会话。
- 学生端、师傅端帮助文案统一为“先提交返修申请、管理员审查通过后才生成返修单”，与后端业务规则一致。
- 修复 MySQL 师傅主责楼栋读取：从 `t_worker_building` 取 `is_primary=1` 的楼栋，不再依赖兼容视图的空字段。
- 已对当前 MySQL 执行角色分表、返修审查、到期字段和兼容视图迁移。
