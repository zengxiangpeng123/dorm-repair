# 三端独立应用拆分

| 项 | 内容 |
|---|---|
| 状态 | 🟡 本地实现与验证完成，待独立部署 |
| 目标 | 将学生端、师傅端、管理端从同一 Vue 演示工程拆成独立入口、路由、鉴权、API、样式、构建和部署单元 |
| 依赖 | 第一次身份改造 |
| 范围 | 前端应用边界、权限隔离、共享契约、独立构建与部署 |
| 原则 | 共享数据和接口，不共享角色身份、页面、操作权限或演示入口 |

## 当前结果

学生、师傅、管理端已拆成三个独立 Vue 应用，分别使用 5173、5174、5175，拥有独立入口、router、session、API、样式和构建。旧 `app/web` 保留为历史参考；正式三端不再共享页面、身份存储或命令客户端。
