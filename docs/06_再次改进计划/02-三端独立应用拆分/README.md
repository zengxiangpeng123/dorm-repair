# 三端独立应用拆分

| 项 | 内容 |
|---|---|
| 状态 | ⬜ 未开始 |
| 目标 | 将学生端、师傅端、管理端从同一 Vue 演示工程拆成独立入口、路由、鉴权、API、样式、构建和部署单元 |
| 依赖 | 第一次身份改造 |
| 范围 | 前端应用边界、权限隔离、共享契约、独立构建与部署 |
| 原则 | 共享数据和接口，不共享角色身份、页面、操作权限或演示入口 |

## 当前问题

当前 `app/web` 只有一个 `main.js`、一套 router、一个 `session.js` 和一个 API 聚合文件。三端仅通过 `/student`、`/worker`、`/admin` 路径切换，仍能互相导入代码，并存在统一登录、切换身份和演示接口。
