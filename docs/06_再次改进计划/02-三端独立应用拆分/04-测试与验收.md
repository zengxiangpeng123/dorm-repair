# 04 测试与验收

## 隔离测试

- 构建扫描：任一应用入口及依赖闭包不得包含其他端 views、API 命令、会话、路由或演示组件。
- 静态依赖检查：禁止跨端 import、共享可变身份和 `opts.role`。
- 生产包扫描：无 `ACTORS` 默认账号、`X-Actor-*`、`demo/reset`、`demo/advance` 或跨端路由。
- 三端分别执行 build、Vitest、浏览器加载与截图。

## 权限与业务测试

| 场景 | 预期 |
|---|---|
| 学生访问师傅/管理端深链 | 无页面权限，后端调用 403 |
| 师傅访问管理端接口 | 403 |
| 学生调用派工/管理命令 | 403；前端无此调用路径 |
| 三端同时登录不同账号 | 会话互不覆盖、不串号 |
| 学生申请返修、管理员批准 | 原单 VERIFYING → REWORKING，生成 -R1 |
| 管理员驳回误报 | 不生成子单，原单继续验收/归档 |
| 师傅执行本单操作 | 正常；他人工单返回 403 |
| 状态机回归 | 9 状态、14 转移、126 矩阵不变 |

## UI 验收

- 学生、师傅端在真实手机尺寸及 430 px 检查；管理端在 1440 px 检查。
- 登录、空态、加载、错误、审查弹层、深链刷新和退出均无错位。
- 任一端的 CSS 修改不影响其他端截图。

## 完成定义

独立目录、独立构建、独立会话、独立发布、跨端权限拒绝、业务回归、截图和回滚证据全部归档，才允许将本迭代标为完成。
