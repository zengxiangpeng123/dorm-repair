# 01 目标与范围

## 目标

学生端、师傅端、管理端形成三个独立 Vue 应用，分别拥有入口、路由、登录、会话、API 客户端、样式、构建产物和部署配置。

## 目标边界

| 应用 | 独立负责 | 不得包含 |
|---|---|---|
| `student-web` | 报修、我的工单、验收、返修申请、本人照片 | 师傅派工、管理端配置、审查队列、自检台 |
| `worker-web` | 本楼待办、到门、完工、缺件、返修子单 | 学生身份切换、管理端配置、审查与系统接口 |
| `admin-web` | 返修审查、例外、台账、参数、授权查询 | 学生代验收、师傅代完工、系统令牌冒领 |
| `shared-contract` | DTO、枚举、错误对象、时间/格式纯函数 | 页面、token、命令、路由、网络副作用 |

## 不变量

1. 三端可以使用同一后端和数据库，但不得共享可写身份存储。
2. 学生端不能 import 管理端或师傅端模块；师傅端不能 import 学生端或管理端模块。
3. 路由守卫只提供用户体验，真正权限由后端验证。
4. 不允许通过前端 opts.role、X-Actor、URL 参数或本地默认身份提权。
5. 状态机不变，仍保持 9 状态、13 转移；返修仍先管理员审查。
6. 旧应用仅在迁移窗口只读保留，不作为永久双轨。

## 非目标

- 不为了“独立”复制三份后端或三套业务数据库。
- 不在本次重写业务逻辑或更换框架。
- 不把共享组件做成可以修改他人身份的通用容器。
