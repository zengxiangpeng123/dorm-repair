# 00 变更摘要与现状

## 变更摘要

当前系统是“三端页面在同一工程中联动”，不是三个独立应用。要改为学生端、师傅端、管理端分别构建、分别运行、分别鉴权，保留后端统一业务接口作为唯一事实源。

## 当前耦合证据

| 位置 | 现状 | 问题 |
|---|---|---|
| `app/web/src/main.js` | 单入口加载全局路由与全局样式 | 不能独立构建 |
| `src/router/index.js` | 同一文件注册三端、登录、自检台和入口页 | 任何端都可携带其他端代码 |
| `src/api/session.js` | `dorm.actor`、`dorm.session`、ACTORS、默认身份 | 三端共享身份和本地状态 |
| `src/api/request.js` | 根据路径猜角色，并可注入 X-Actor 头 | 前端角色判断影响请求身份 |
| `src/api/orders.js` | 聚合所有端 API，并允许 opts.role 临时换身份 | 客户端可越权调用他端接口 |
| `Entry.vue` | 三端入口、重置、快进、自检台混放 | 演示能力进入业务入口 |
| `BottomNav.vue` | 一个组件同时包含学生和师傅导航 | 角色 UI 耦合 |
| `src/styles/tokens.css` | 三端全部视觉样式全局加载 | 样式互相污染 |
| 构建与部署 | 一个 dist、一个 Vite 端口 | 不能独立发布和回滚 |

## 分离不等于复制三套后端

- 后端仍统一保存工单、权限、状态和历史。
- 三端只调用各自需要的 API；权限仍由后端强制执行。
- 公共 DTO、状态和错误格式可共享，但不共享会话、页面或命令。

## 具体违规调用清单

| 位置 | 当前行为 | 分离后 |
|---|---|---|
| `student/New.vue` | 学生建单后前端直接调用 `/orders/{no}/assign`，并用 `role: 'system'` 换身份 | 学生只提交；派工由后端内部规则完成，学生端不得存在 `/assign` 调用 |
| `worker/Task.vue` | `isMine` 固定返回 `true`，未真正校验当前师傅归属 | 由后端归属校验 + 当前师傅 ID 判断；其他师傅工单 403 |
| `Entry.vue` | 三端入口、重置、快进、自检台同页 | 移出生产；测试工具独立受控 |
| `api/orders.js` | 三端全部命令集中在一个对象，可用 `opts.role` 换身份 | 每端独立 API 客户端；禁止角色切换参数 |
| `api/request.js` | 无 token 时按路径猜角色并注入 `X-Actor-*` | 无 token 直接 401；生产删除请求头冒充路径 |
| `api/session.js` | 三端共享 `dorm.actor` / `dorm.session` | 三端独立会话 key 与登录流程 |
| `BottomNav.vue` | 学生和师傅导航在同一组件内按 role 分支 | 各端独立导航组件 |
| `tokens.css` | 三端样式全部全局加载 | 拆分基础 token 与各端样式入口 |
