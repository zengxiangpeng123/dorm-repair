# 03 实施任务与顺序

## 任务拆解

| ID | 任务 | 验收出口 | 状态 |
|---|---|---|---|
| S01 | 冻结三端路由、API、状态、会话与构建依赖图 | 现状清单与边界评审通过 | ⬜ |
| S02 | 建立 workspace 与纯 `shared-contract` | 共享包无网络/身份/路由副作用 | ⬜ |
| S03 | 迁移学生端独立入口、会话、路由、API 和样式；移除建单后前端 `/assign` | 独立构建，学生链通过 | ⬜ |
| S04 | 迁移师傅端独立入口、会话、路由、API 和样式；修正归属判断 | 独立构建，师傅链通过 | ⬜ |
| S05 | 迁移管理端独立入口、会话、路由、API 和样式 | 独立构建，审查链通过 | ⬜ |
| S06 | 移除跨端导入、身份切换、opts.role 与生产演示入口 | 隔离扫描无违规 | ⬜ |
| S07 | 三端权限、构建、截图、端到端回归 | 测试与截图证据齐全 | ⬜ |
| S08 | 三端灰度发布、深链验证与回滚 | 独立发布和回滚通过 | ⬜ |

## 推荐提交顺序

```text
chore(web): 建立三端 workspace 与契约包
refactor(student): 拆出学生独立应用
refactor(worker): 拆出师傅独立应用
refactor(admin): 拆出管理独立应用
fix(auth): 移除跨端身份与系统命令耦合
test(web): 补齐三端隔离与业务回归
chore(deploy): 配置三端独立发布与回滚
```

## 禁止事项

- 禁止只复制三个目录而继续共享同一 session、router 和聚合 API。
- 禁止保留从学生页调用 `/assign`、`/admin/*` 或系统令牌接口的前端路径。
- 禁止用前端隐藏按钮替代后端权限校验。
- 禁止一次大改后只跑一次总构建，必须逐端构建和验证。
