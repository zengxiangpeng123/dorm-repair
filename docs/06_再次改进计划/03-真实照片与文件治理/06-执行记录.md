## 实际改动

- 新增 `t_file` 文件元数据表和 `t_work_order_photo.file_id` 关联；迁移脚本为 `db/migrations/20261118_file_metadata.sql`。
- 新增 `FileStorage` 抽象：本地私有存储用于开发，S3 兼容对象存储用于生产。
- 新增 `POST /files`：登录后上传，服务端生成对象键；校验大小、声明 MIME、文件签名、扩展名，并计算 SHA-256。
- 新增 `GET /files/{id}`：仅上传者、本单学生、本单师傅和管理员可读；未绑定文件只有上传者或管理员可读。
- 学生建单与师傅完工改为提交 `photoIdsBefore` / `photoIdsAfter`；文件只能绑定一张工单，重复绑定被拒绝。
- 三端新增真实文件选择、上传中状态、图片预览；管理端返修审查展示现场照与完工照。
- 生产 profile 强制 S3 私有桶，并禁止旧演示照片兼容开关。
- 新增孤儿文件清理任务：默认 24 小时后删除未绑定工单的对象和元数据，支持保留期与批大小配置。
- 清理使用数据库租约，避免多实例重复删除同一对象；失败会释放租约并在下一轮重试。
