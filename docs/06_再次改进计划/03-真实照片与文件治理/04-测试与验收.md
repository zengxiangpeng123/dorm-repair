# 04 测试与验收

## 测试范围

- 保留既有 JUnit、pytest、Vitest 和 M1–M5 回归。
- 新增本迭代专属测试：MIME/大小/权限/恶意文件、存储失败与清理测试。
- 必须覆盖成功、失败、越权、重复、并发、超时、重启和回滚场景。

## 验收判据

1. 目标行为已在真实运行环境验证，不是只验证内存 mock。
2. 字段、权限、错误码和数据库事实源一致。
3. 失败不会写半成品；重试不会重复创建数据。
4. 生产演示入口关闭，密钥、令牌和个人信息不进入日志。
5. 测试结果、截图、日志、迁移对账和回滚证据写入 `06-执行记录.md`。

## 不允许替代的证据

- 单次 HTTP 200 不等于完整验收。
- 规则 pytest 不等于真实模型联调。
- 截图不等于权限、性能或安全验证。
- 构建通过不等于生产可部署。
