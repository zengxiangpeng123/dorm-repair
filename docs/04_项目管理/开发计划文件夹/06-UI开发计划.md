## 二、返修审查 UI

```text
学生详情
  └─ [申请返修] → 原因输入 → 待验收 + 返修审查中

管理端 → 返修审查
  ├─ 工单号 / 位置 / 师傅 / 返修次数
  ├─ 学生原因 / 完工照 / 时间线
  └─ [确认返修] [驳回申请]
```

- 批准后刷新原单和子单。
- 驳回后刷新原单，提示继续验收/归档。
- 409 时关闭提交态并刷新；422 保留用户输入。
- 颜色与文字同时表达状态，不能只靠颜色。
