## 三、必改代码点

- `TransitionTable`：`REJECT` 增加 `ADMIN`；TRIGGER 增加 `REWORK_REQUEST -> STUDENT`、`REWORK_REJECTED -> ADMIN`。
- `OrderEvent`：增加 `REWORK_REQUEST`、`REWORK_REJECTED`，`changesStatus=false`；EVENTS 和矩阵仍保持 13/130。
- `TimerService`：PENDING 审查暂停 T1，批准后终止，驳回后按决定时间重置。
- `UserRepository`：`find/all/count/insert/setPassword` 全部按角色表路由。
- `OrderService.assign`：只按楼栋和主负责师傅派工；无师傅返回 422，保持 PENDING，不再回退 `W0428`。
- `OrderService.reject`：拆为旧兼容路径和新审查路径；新路径返回 `{original,reworkOrder}`。
- `t_rework_review`：使用 `attempt_no` 保留每次申请，`rework_index` 批准后才赋值。
- `v_user_account`：删除顺序为停写 → 删视图 → 删 `t_user`；回滚窗口在删视图之前。
- `t_building.floors`：同步修改 schema、data 和 MetaController 三处。
- 端口迁移覆盖配置文件、启动脚本、验收脚本、AGENTS.md 和 build_docs.py。
- `build_docs.py`：更新表数、端口和验收数字后重新生成 CG01–CG14。

## 五、计划使用规则

- 每日更新 WBS 的“状态”和“实际工时”列：`⬜ 未开始 / 🚧 进行中 / ⛔ 阻塞 / ✅ 完成`。
- 单人顺序执行；任何并行都视为加班，不计入正常排期。
- 每阶段必须通过门禁，才能进入下一阶段。
- 旧计划移入 `old/`，只读保留，不再执行。
